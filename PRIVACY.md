# Privacy

GT6Replay has no analytics, accounts, advertising, cloud storage, or automatic uploads. Replay data stays on the user's PC.

Network access is limited to console FTP or telemetry actions started by the user. The application does not contact GitHub or download code during playback. An external decoder is executed only when configured by the user.

Replays and exports can contain driver names, dates, local source paths, and console addresses from recordings. Inspect exported files before sharing them. The repository and release package contain only synthetic test inputs and no personal replay data. FTP passwords are not saved by the application.
