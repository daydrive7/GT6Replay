# 0.1.0 Release

- Offline playback of decoded GT6 replays, with all cars visible by default.
- Track-map and schematic 3D views with pan, zoom, and orbit controls.
- Speed, RPM, gear, and lap telemetry for the selected driver.
- Sortable position, driver, best-lap, race-time, gap, lap, result, and car columns.
- Replay, race-report, and telemetry export.
- Optional console FTP and telemetry recording.
- External decoder interface and content-matched replay caching.

Protected-save decoding is supplied by an external tool, not by this release. No game engine code, assets, savedata-decryption keys, examples, or personal recordings are distributed. The optional telemetry recorder uses the published SimulatorInterface protocol. Read `README.md` and `THIRD_PARTY.md` before redistributing the Windows build.

Corresponding Qt/PySide source archives are release assets alongside the Windows ZIP. Checksums are provided for the application and source archives. The Windows executable is unsigned.
